# Lung Tumor Segmentation

An end-to-end deep learning project for segmenting lung tumors in CT scans using a 3D U-Net built with PyTorch and MONAI. It covers data preparation, training, evaluation and a small web demo hosted on Hugging Face, with automated testing and deployment through GitHub Actions. Trained on the Lung task of the Medical Segmentation Decathlon. For research and learning purposes only, not for clinical use.

Data: Medical Segmentation Decathlon, Task06 Lung (CC-BY-SA 4.0). Citation: Antonelli et al., The Medical Segmentation Decathlon, 2022.
